\# ResolveIQ — AI-Powered Incident Resolution Platform



ResolveIQ is a production-style backend project that helps engineering teams analyze incidents faster. It ingests application logs and incident reports, generates AI-based summaries, retrieves similar past incidents using vector search, and recommends possible root-cause fixes.



\## Tech Stack



\- Java Spring Boot

\- Python FastAPI

\- PostgreSQL

\- Redis

\- Docker

\- Vector Search / Embeddings

\- GitHub Actions



\## Core Features



\- Upload and store application logs

\- Generate AI-based incident summaries

\- Retrieve similar past incidents using embeddings

\- Recommend possible root-cause fixes

\- Cache frequent queries using Redis

\- Provide REST APIs for incident tracking

\- Dockerized local development setup



\## Planned Architecture



Frontend / API Client  

→ Spring Boot Backend  

→ PostgreSQL + Redis  

→ Python AI Service  

→ Vector Search Engine
